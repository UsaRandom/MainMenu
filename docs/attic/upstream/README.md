# Upstream user guide

These files shipped with [N64FlashcartMenu](https://github.com/Polprzewodnikowy/N64FlashcartMenu).
They describe that product: a file browser, an MP3 player, 64DD disks, background images, and
flashcarts this fork does not build for.

They are here so a citation still resolves and so nobody has to reconstruct what was promised.
They are not the manual. That is [CARD.md](../../CARD.md) and [BUILDING.md](../../BUILDING.md).
